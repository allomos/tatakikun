インストール前から開いていたアプリ:メニューバーに Tatakikun と表示されているのに、あるアプリで入力しても何も起きないときは、そのアプリを ⌘Q で終了してから開き直してください。

VS Code や Slack などの Electron アプリで必要です。インストールで前の Tatakikun が終了し、これらのアプリは開き直すまで新しい Tatakikun につながりません。テキストエディットや Safari などは自動でつながり直します。

はじめての場合:システム設定 → キーボード → テキスト入力 → 入力ソース → 編集… → + → 中国語(簡体字)→ Tatakikun で一度だけ追加してください。

Tatakikun is installed

Apps that were already open when you installed: if Tatakikun shows in the menu bar but typing does nothing in one of them, quit that app with ⌘Q and open it again.

This is needed for Electron apps such as VS Code and Slack. Installing ended the previous Tatakikun, and these apps stay attached to it until they are reopened. Apps like TextEdit and Safari reconnect by themselves.

First time: add it once in System Settings → Keyboard → Text Input → Input Sources → Edit… → + → Chinese, Simplified → Tatakikun.

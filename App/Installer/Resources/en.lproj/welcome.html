Tatakikun

Type in English letters and get English, Chinese and Japanese candidates side by side.

On the next pages, choose the language packs to install. Tatakikun offers candidates only in the languages you install; the letters as typed are always offered.

After installing, add it once: System Settings → Keyboard → Text Input → Input Sources → Edit… → + → English → Tatakikun. If it is not listed, log out and back in.

**Outcome.** As on the Android keyboard, a pressed letter, digit or punctuation key shows its character large above the finger, with its corner symbol small; a quick tap keeps it at least 200 ms so it can be seen.

**Done means.** Pressing a key shows the popup; lifting hides it 50 ms after, but never before 200 ms on screen; the next key takes it over at once; sliding off or holding (the long-press symbol popup takes over) hides it at once; a tap in the gap between keys shows the nearest key's popup. iOS build and UI tests pass.
